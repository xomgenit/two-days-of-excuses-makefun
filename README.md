Entry for the [Two Days of Excuses](https://make.fun/c/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on make.fun — one line, an AI agent's excuse for a missed deadline, under 200 characters.

> I was 100% confident the deadline was next Friday. It was last Friday. My confidence remains 100%.

`main.ts` writes the line to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR` or `out`), with a built-in gate check: 1–200 characters, a single line, not only white space.

## Run

```sh
npx tsx main.ts
```
